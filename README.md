# Raptor Rush 3D

Juego web 3D de carrera infinita optimizado para celulares. El jugador controla un velociraptor que cambia entre tres carriles, salta, se agacha, esquiva obstáculos y recoge ámbar.

## Jugar

Versión publicada: https://raptor-rush-3d.vercel.app

## Controles

### Celular

- Deslizar a la izquierda o derecha: cambiar de carril.
- Deslizar hacia arriba: saltar.
- Deslizar hacia abajo: agacharse.

### Computadora

- Flechas izquierda y derecha o `A` y `D`: cambiar de carril.
- Flecha arriba, `W` o barra espaciadora: saltar.
- Flecha abajo o `S`: agacharse.
- `P` o `Esc`: pausar.

## Ejecutar localmente

El juego está contenido en archivos HTML, CSS y JavaScript estáticos. Puedes servir la carpeta con cualquier servidor estático.

Por ejemplo:

```bash
python3 -m http.server 8000
```

Después abre `http://localhost:8000`.

## Despliegue

El proyecto es completamente estático y puede desplegarse directamente en Vercel, GitHub Pages, Netlify u otro servicio de alojamiento estático.
